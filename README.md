🛍️ ShopEase - E-Commerce Website

Welcome to ShopEase! ✨

ShopEase is a responsive E-Commerce Website created using HTML, CSS, and JavaScript. It provides a simple and attractive online shopping experience.

🌟 Features

- 🏠 Attractive Home Page
- 🛍️ Product Listings
- 🔍 Search Products
- 🗂️ Category Filter
- 🛒 Add to Cart
- ➕ Increase Product Quantity
- ➖ Decrease Product Quantity
- ❌ Remove Products from Cart
- 💰 Automatic Total Price Calculation
- 📱 Responsive Design
- 🎨 Modern and Aesthetic UI

💻 Technologies Used

- HTML5
- CSS3
- JavaScript


🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Browse the products.
5. Search and filter products.
6. Add products to your cart.
7. View the total price.
